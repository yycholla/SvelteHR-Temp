# SvelteHR Tech Stack

## Frontend Framework

- **SvelteKit 5**: Meta-framework with SSR/SPA capabilities
- **Svelte 5**: Component framework with runes syntax ($props, $state, $bindable)
- **TypeScript**: Strict typing throughout the application
- **Vite 7.0.4**: Build tool and development server

## Styling & UI

- **TailwindCSS 4.0**: Utility-first CSS framework with custom design system
- **Skeleton UI 3.1.7**: Component library built for Svelte
- **Bits UI 2.9.1**: Headless UI primitives
- **Tailwind Variants 1.0.0**: Component variants system
- **Lucide Svelte**: Icon library

## State Management & Data

- **tRPC 11.4.4**: End-to-end typesafe APIs
- **Zod 4.0.14**: Runtime type validation and schema parsing
- **Better Auth 1.3.4**: Authentication library
- **Svelte Stores**: Built-in reactive state management
- **SvelteKit Superforms 2.27.1**: Form handling with validation

## Development Tools

- **Vitest 3.2.3**: Unit testing framework
- **Playwright 1.49.1**: End-to-end testing
- **Storybook 9.1.1**: Component development and documentation
- **ESLint 9.18.0**: Code linting with TypeScript and Svelte plugins
- **Prettier 3.4.2**: Code formatting with Svelte and Tailwind plugins

## Utilities & Libraries

- **ky 1.8.2**: HTTP client for API requests
- **js-cookie 3.0.5**: Cookie handling
- **jsonwebtoken 9.0.2**: JWT token management
- **svelte-dnd-action 0.9.64**: Drag and drop functionality
- **clsx 2.1.1** & **tailwind-merge 3.3.1**: Conditional class merging

## Backend

- **Go**: Backend API server
- **PostgreSQL**: Database (inferred from migrations structure)
- **RESTful API**: Comprehensive HR management endpoints
- **MCP Server**: Model Context Protocol integration for AI tools
